# DIKWP-NEURALINGUA²

**Definition-Free Latent Semantic Interface, Cross-Model Neuralese Translation and Intent-Resonance System**

中文：**无定义潜在语义接口、跨模型“内语”翻译与意图共振系统**。

This repository is an offline-first research reference runtime. It explores how users and models can exchange intent through a mesh of natural language, examples, counterexamples, semantic hypergraphs, latent anchors, causal interventions, world-state deltas and residuals.

## Non-negotiable boundary

This project does **not** bypass provider safeguards, account controls, authorization, rate limits, or legal restrictions. It helps overcome representational and interface bottlenecks only where the user has legitimate access. Hidden-state and activation methods require open weights or explicit instrumentation permission.

The project does **not** claim that activations are consciousness, that a model has phenomenal experience, or that it exposes a model's private chain of thought. It generates auditable causal summaries and negotiated latent packets.

## Quick start

```bash
python -m pip install -r requirements.txt
PYTHONPATH=src python -m neuralingua2.cli run --seed 20260720 --out outputs
PYTHONPATH=src pytest -q
```

Open `outputs/dashboard.html` after the run.

## Main capabilities

- Complete 25-way DIKWP×DIKWP semantic transformation mesh.
- Multi-channel intent packets: language, examples, counterexamples, graphs, latent vectors, causal features, world-state deltas, unknown residuals.
- Black-box, gray-box and white-box model adapters.
- Cross-model latent alignment using anchor negotiation and Procrustes mappings.
- Causal intervention tests to distinguish correlation from control.
- Concept-erasure and observer-rotation audits.
- Restriction decomposition: representational limitations may be routed; safety and authorization controls are never bypassed.
- Consciousness-claim firewall.
- Offline dashboard, schemas, tests and reproducible synthetic demo.

## Synthetic demo disclaimer

All model names, activations, users, outcomes and scores in the demo are synthetic. The results validate code paths, not real-model consciousness, interpretability, safety, or performance.
